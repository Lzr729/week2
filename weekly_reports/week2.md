# Week2 周报

## 一、本周工作概览

本周主要完成了对 8 家拟上市公司的招股说明书的抽取、校验和整理工作，形成了 JSONL、Excel 三表抽取以及关键页批注 PDF，完成流程如下：

1. **PDF 下载与候选文本定位**
   - 抓取 8 家公司的招股说明书 PDF。
   - 将每份招股说明书解析成文本，标注页码并定位候选段落。

2. **JSONL 文件生成**
   - 抽取两类记录：`subscription_flow`（认缴流量）和 `equity_snapshot`（股权结构存量）。
   - 每条记录包含 PDF 页码、股东/认购方、快照时间、原文证据等。
   - 使用 Pydantic schema 校验，确保字段完整且符合结构要求。

3. **三表抽取 Excel**
   - **表1：增资扩股认缴流量表**
     - 每行对应一次认购，包含认购方、认购数量、认购金额、认购价格、原文证据。
   - **表2：股权结构存量表**
     - 每行对应一名股东在某一时点的持股/出资情况。
     - 保留 t0｜报告期初，t1、t2 等增资后的股权结构。
   - **表3：schema 与 cross-check 校验表**
     - 核对上一时点股本/持股数与本次认缴变化是否与下一时点股本/持股数一致。
     - 已处理“待复核”行，特殊口径（如友升股份 t0、整体变更折股）标记备注说明。

4. **关键页批注 PDF**
   - 根据 JSONL 的 `pdf_page` 字段抽取关键页，生成每家公司一份批注 PDF。
   - 批注包含每条记录对应的行号、record_type、股东/认购方、快照时间/认购日期、原文证据摘要。
   - 同时生成 `关键页索引.csv`，便于追溯每条记录对应的 PDF 页面。

## 三、LLM 使用情况说明

1. **是否使用 LLM**：未使用 LLM API 批量抽取，主要使用规则定位 + 人工复核。
2. **辅助用途**：
   - 生成/修改抽取脚本
   - 理解复杂股权结构口径
   - 校验 cross-check 异常
3. **最终结果依据**：JSONL、Excel、关键页批注 PDF、校验日志。

## 四、存在问题与处理方式

1. **友升股份 t0 口径**
   - 抽取时 t0 为有限公司注册资本/出资额，与股份公司股本口径不同。
   - 已在表3备注中说明口径转换，并不作为错误。

2. **整体变更折股 / 非认缴流量**
   - 跨公司存在股权转让、整体变更折股或资本公积转增情况。
   - 表3 已处理，校验结果为 pass，并在备注中说明特殊口径。

3. **三协电机表3行数较少**
   - 原始 PDF 仅提供一个可识别完整股权结构时点，已在周报备注说明。
